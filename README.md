# KLidKeeper — Настройки поведения ноутбука при закрытии крышки (KDE Plasma 6)

**KLidKeeper** (`org.kde.klid`) — нативный виджет для панели задач и системного трея **KDE Plasma 6**, позволяющий гибко управлять поведением ноутбука при закрытии крышки.

---

## Возможности и настройки

1. **Предотвращать сон при закрытии крышки (Keep Awake on Lid Close):**
   - Вызывает `org.freedesktop.login1.Manager.Inhibit("handle-lid-switch:sleep", ...)` в `systemd-logind`.
   - Ноутбук **не переходит в спящий режим** при закрытии крышки: фоновые загрузки, музыка, серверы и сборка продолжают работать.
2. **Экран при закрытии крышки (Display Action on Lid Close):**
   - 🖥️ **Выключать экран (DPMS Off):** *(рекомендуется)* при закрытии крышки подсветка матрицы выключается, чтобы экран не грелся и экономилась батарея. Как только крышка открывается — экран моментально включается обратно.
   - 🔅 **Понижать яркость до минимума:** при закрытии крышки яркость плавно сбрасывается до 0%, а при открытии — восстанавливается предыдущий уровень.
   - 💡 **Не изменять:** экран остаётся включенным в обычном режиме.
3. **Предотвращать блокировку экрана (Prevent Screen Lock):**
   - Предотвращает автоматическую блокировку сессии экраном блокировки KDE (`org.freedesktop.ScreenSaver.Inhibit`) во время работы с закрытой крышкой или при простое.
4. **Управление в один клик:**
   - **Средний клик (колесико мыши)** по иконке в трее/панели: моментально переключает режим (включить / выключить бодрствование) без открытия меню.
   - **Левый клик:** открывает красивое меню настроек.
   - **Динамическая иконка в трее:** статусная чашка кофе (наполненная горячим кофе при активном режиме, пустая — в обычном).
   - Все настройки автоматически сохраняются в конфигурации пользователя.

## Установка

Плазмоид и плагин устанавливаются в пользовательский каталог `~/.local` без необходимости прав `sudo`:

```bash
cd ~/Dev/cpp/KLidKeeper

# 1. Конфигурация и сборка
cmake -B build -S . -DCMAKE_INSTALL_PREFIX=$HOME/.local
cmake --build build

# 2. Установка плагина, иконок и плазмоида
cmake --install build

# 3. Обновление плазмоида в Plasma 6
kpackagetool6 --type Plasma/Applet --upgrade package/ || kpackagetool6 --type Plasma/Applet --install package/
```

### Как добавить на панель задач или в системный трей:
1. Кликните правой кнопкой мыши по панели задач KDE или рабочему столу.
2. Выберите пункт **«Добавить виджеты…»** (или нажмите `Meta+W`).
3. Введите **KLidKeeper** в строке поиска.
4. Перетащите виджет на панель или в системный трей.
